# 第三方组件

Windows 完整包中的 `Microsoft.Windows.SDK.NET.dll` 和 `WinRT.Runtime.dll` 来自 [Microsoft.Windows.SDK.NET.Ref 10.0.22621.57](https://www.nuget.org/packages/Microsoft.Windows.SDK.NET.Ref/10.0.22621.57)。这些文件随伴侣原样分发，用于调用 Windows Runtime API。

- [Microsoft Windows SDK 许可条款](https://learn.microsoft.com/en-us/legal/windows-sdk/license)
- [Microsoft Windows SDK 可再分发文件列表](https://learn.microsoft.com/en-us/legal/windows-sdk/redist#microsoftwindowssdknetref)
- [Microsoft C#/WinRT 源码及许可](https://github.com/microsoft/CsWinRT)
