# 流光视觉与交互规范

适用于以流光为参考的 Apple 风格网页、桌面界面和浏览器扩展。风格安静、简洁，控件有清楚的触感。优先延续流光的比例、材质和交互节奏。

## 版式

用近似黄金比例递增的 **8、13、21、34 px** 建立间距节奏。以内容尺寸和可读性为准。

| 间距 | 用途 |
| --- | --- |
| 8 px | 同组图标与文字、密集列表项 |
| 13 px | 小型玻璃容器内边距 |
| 21 px | 窄屏左右留白、明显分组 |
| 34 px | 主区块留白，例如时钟与搜索框 |

- 用一条中轴组织日期、时间和搜索。主操作靠近视觉中心，辅助入口放在边缘或下方。
- 一个状态保留一个主焦点。静息时由时钟和搜索形成层次，输入时让搜索框成为最亮的元素。
- 图标基准 22 px，统一轮廓、线重和留白。站点图标可保留自身色彩，容器使用统一圆角和高光。
- 窄屏先收间距，再缩宽度，确保文字和操作区可用。

## 磨砂玻璃与文字

用半透明基底、轻微渐变、轮廓高光、内描边和模糊建立材质。搜索框、设置按钮、侧栏和菜单共用材质。缩放时保留可辨识的边缘。

| 变量 | 流光参考值 |
| --- | --- |
| 深色底 | `#100d1c` |
| 玻璃基底 | `#17142374` |
| 玻璃边线 | `#eae0ff38` |
| 焦点色 | `#c6b4ff` |
| 背景滤镜 | `blur(24px) saturate(145%)` |
| 文字 | `Segoe UI Variable`、`Microsoft YaHei UI`、系统无衬线 |

- 正文、辅助说明和强调色形成有节制的对比。时钟用等宽数字，分钟更新时中轴保持稳定。
- 在亮壁纸、暗壁纸和高频背景上检查可读性。高对比或减少透明度时使用实底和可见边界。
- 壁纸承担氛围。保留有组织的留白，控件旁的文字服务识别或操作。

## 动效

| 交互 | 时间参考 | 行为 |
| --- | --- | --- |
| 悬停与按压 | 150–280 ms | 局部柔光渐亮，图标抬起约 1 px，按压轻微收缩。 |
| 搜索聚焦 | 380–540 ms | 搜索框轻微拉宽，柔光渐亮，周围内容同步淡下去。 |
| 设置面板展开与关闭 | 320 ms | 从齿轮原位铺开，沿相同路径收回。玻璃轮廓和内容共享进度。 |
| 设置分组 | 310 ms | 横向翻页，选中色块同速平移，宽度与圆角保持一致。 |
| 右键菜单 | 展开 230 ms，收回约 177 ms | 从实际落点向四周显现，关闭时沿同一路径缩回。靠窗沿时调整菜单位置，保留落点。 |
| 壁纸网格换列 | 260 ms | 卡片从当前位置滑入新格位，反向拖动时连续接续。 |
| 快捷栏变化 | 150–220 ms 每段 | 新图标淡入并轻微放大，移除时缩小淡出，相邻项滑动补位。 |

- 优先从触发位置建立连续变化。重复触发或反向操作时从当前可见状态续接。
- 常规状态切换采用克制的平移。倾向一段连续缓动，按压反馈只用小幅缩放。
- 尊重系统减少动态效果和减少透明度。状态、焦点和可操作性始终清楚。

## 验收

1. 在宽屏和窄窗口检查静息、悬停、聚焦和面板展开四个状态。
2. 用浅色与深色壁纸检查玻璃层对比和边线。
3. 快速连续点击、反向切换、拖到边缘，检查过渡是否连续。
4. 用键盘与减少动态效果模式完成同样的操作。
